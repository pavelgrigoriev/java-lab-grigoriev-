Java Lab Project

Учебный проект по курсу «Git, GitLab/GitHub и документация». Реализует калькулятор на Java.

Функциональность

  • Класс Main — точка входа приложения.
  • Класс Calculator — методы add и divide.

Сборка и запуск

mkdir -p build
javac -d build src/*.java
java -cp build Main

Пример использования

Calculator calc = new Calculator();
int sum = calc.add(2, 3);        // → 7
int div = calc.divide(10, 2);    // → 5
